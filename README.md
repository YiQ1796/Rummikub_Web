# 猴三毛拉密 Rummikub — 可執行基底 V0.1.1（2026-11-02）

這是第三款網頁遊戲的 **獨立基底**。單機由 1 位真人和 1–3 位 AI 對戰，總座位 2–4 人；正式多人連線尚未加入，**不可宣稱真人跨網遊玩已完成**。不使用任何產生的新圖片；只有使用者提供的角色參考圖保存在 `art/reference/`，遊戲牌目前都是 CSS＋文字佔位。

## 開啟遊戲

**Windows 10／11 最簡單：直接雙擊 `啟動遊戲_免安裝.bat`。** 它會以 Windows 內建 PowerShell 在 localhost:8765 啟動靜態伺服器並打開瀏覽器，不需要安裝 Node.js 或 Python。關閉該 PowerShell 視窗便停止服務。若連接埠 8765 被占用，請先關閉舊伺服器。

也可以用 Python（若電腦已有安裝）啟動；ES Modules 必須透過 HTTP 開啟，不能直接雙擊 `index.html` 用 `file://`：

```powershell
python -m http.server 8000
```

然後用瀏覽器進入 `http://localhost:8000/`。如未安裝 Python，可用任何標準靜態網站伺服器，或日後部署至 GitHub Pages。

## 已實作
- 106 張牌（四色 1–13 每組兩份，共 104 張，再加 2 Joker）；2–4 人各 14 張。
- 群組與順組／Joker 替代判定；首次破冰只能用自己的牌且需達 30 分。
- 本回合可建立新牌組、把選牌併入既有牌組、拆牌移到暫存區、把原本手牌取回牌架、整回合復原。
- 提交前會驗證全部牌組合法、牌張沒有重複／遺失，且本回合至少打出 1 張手牌。
- 抽一張結束；失誤確認後還原桌面並罰抽最多三張；出完牌勝利與手牌扣分。
- AI 自動補足、AI 會嘗試 30 分破冰、下新牌組及延伸牌組（策略尚非最佳化）。
- 完全沒有玩家思考倒數，也沒有因時間流逝自動結束回合。
- 使用 localStorage 保存本機進度，重新整理後可恢復（使用帶版本號的存檔格式）。
- 自適應手機／電腦版面，按選牌＋按鈕式操作。

## 已知限制（不可當成完整成品）
1. **尚未實作真人 WebRTC／WSS 房間與跨網路重連。** 也沒有已驗證的伺服器權威狀態。
2. **AI 為基礎策略。** 會建立合法群組、順組與延伸現有牌組，但不會主動拆解／重新安排整張牌桌；大牌架時搜尋也有限制。
3. **Joker 完整交換規範待進一步強化。** 引擎保證提交的牌組合法，但尚未強制「換下 Joker 後在同一回合合法重用」等比賽細節。
4. 遊戲目前支援點選式排牌；觸控拖曳、牌架自由拖放是下一個 UI 階段。
5. 首位玩家暫定真人先手；正式版本需依確定的開局順序規則改動。
6. 當牌池耗盡且整輪無人可出牌時，以剩餘扣分最少者獲勝；平手細節尚待規格決定。
7. 存檔是本機非可信資料，不能當未來多人競技端的權威狀態。

## 目錄
- `src/rules.js`：純規則、牌組與不變量。
- `src/game.js`：對局、草稿交易與回合流程。
- `src/ai.js`：有界的 AI 牌組搜尋。
- `src/main.js`：DOM 互動、存檔與顯示。
- `assets/styles.css`：暫時的單一樣式來源。
- `assets/art-config.js`：兩張 Joker 正式素材映射。
- `tests/`：Node.js 自動化測試。
