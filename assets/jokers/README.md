# 猴三毛拉密 Joker 素材

兩張**已核准的使用者原圖**於 2026-11-02 匯入，保留透明背景。

- `joker_sanmao_smile.webp`：Joker A，微笑猴三毛。
- `joker_sanmao_smirk.webp`：Joker B，俏皮猴三毛。

網站版為 96 × 96 WebP（透明），適合 45 px / 36 px 遊戲牌面顯示。
原始圖片為 1254 × 1254 透明 PNG，保存在正式素材備份包供未來高解析改版，
但 GitHub 網站只需使用 WebP 以減少傳輸量。
其他 104 張數字牌仍由程式與 CSS 繪製，沒有產生額外圖片。
